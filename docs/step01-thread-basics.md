# step01 — Thread와 Runnable

테스트: [`step01_basics/ThreadCreationTest`](../src/test/java/study/thread/step01_basics/ThreadCreationTest.java)

## 이 단계에서 답할 질문

1. "이 코드가 새 스레드에서 실행됐다"를 **눈이 아니라 값으로** 어떻게 증명하나?
2. `start()`와 `run()`은 뭐가 다른가? 차이를 드러내는 결정적 증거는 무엇인가?
3. `Thread`를 상속하는 것과 `Runnable`을 넘기는 것 — 왜 후자를 쓰나?
4. 끝난 스레드를 다시 `start()` 하면 어떻게 되나? 그게 무엇을 뜻하나?
5. `join()`이 돌아왔다는 것은 무엇을 보장하나? 그동안 부른 쪽은 뭘 하고 있었나?
6. `start()` 호출 순서가 실행 순서를 약속하나?
